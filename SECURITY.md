# Security Policy

This repository contains a dual-use security research tool (a Command & Control framework) intended for authorized penetration testing and educational purposes only.

If you have concerns about the content of this repository, or if you believe it is being used in a way that violates GitHub's Acceptable Use Policies, please open an issue on this repository so we can address it directly.

Please do not use this tool against systems you do not own or have explicit permission to test.
